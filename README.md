## 提交 Session 或 Cookie 前，必须看清安全风险

WildAI 的 Pro 订阅流程需要用户提交一段与 ChatGPT 登录状态有关的信息。Pro 5x 的流程还要求导出 ChatGPT Cookie。平台自己也提醒，这些内容只用于本次开通，不要发给其他人。

这类信息不是普通订单编号，也不是可以随手公开的优惠码。它可能代表当前浏览器的登录状态，因此操作时至少要做到：

- 只在确认过的官方平台页面提交。
- 不要把这段内容发给客服以外的陌生人。
- 不要把 Cookie 或 Session 粘贴到群聊、论坛、截图或在线文档。
- 不要在公共电脑上操作。
- 开通完成后检查 ChatGPT 账户的登录设备、活动记录和安全设置。
- 如果发现异常登录、账号被退出或设置发生变化，立即修改密码并终止其他会话。

平台要求提交凭证，是它能够代用户完成订阅的前提，同时也是整个流程中最需要谨慎的部分。只因为“付款方便”就忽略账号安全，不值得。

## 单月和长期订阅，哪种更适合

WildAI 帮助中心将订阅分为单次订阅和长期订阅。

单次订阅通常是购买 1 个月，到期不续费，适合第一次尝试或者只需要短期使用的人。长期订阅则是多月连续订阅，平台页面通常会给出更优惠的月均价格，但具体折扣需要以当前页面为准。

长期订阅有一个容易被忽略的地方：平台帮助文档说明，多月订阅可能按月自动续费或从预存金额中按月执行。若在 ChatGPT 官方页面自行取消，可能导致后续预付月份无法继续使用。

比较稳妥的选择顺序是：

1. 第一次购买，先选单月。
2. 确认账号、网络和使用需求都正常。
3. 确实长期使用，再考虑多月方案。
4. 下单前截图保存套餐、周期、金额和退款规则。
5. 购买后不要重复开通同一账号的多个订阅。

如果你已经在 Apple App Store、Google Play 或 ChatGPT 网页端拥有有效订阅，先确认原订阅由哪个平台管理。OpenAI 提醒，同一个账号在多个平台重复订阅，可能产生两笔独立扣款。

## 付款后没有开通怎么办

遇到付款后没有立即升级，不要先连续点击付款按钮。可以按下面顺序排查：

### 先看订单状态

进入 WildAI 的订单页面，检查订单是否显示“处理中”“已完成”或失败。如果只是处理中，先等待平台说明的时间范围。

### 检查账号邮箱

平台会在付款前显示识别到的 ChatGPT 邮箱。若购买时选错账号，订阅通常不能直接转移到另一个账号。OpenAI 官方也明确表示，ChatGPT 订阅不能在不同账号之间转移。

### 检查是否重复购买

微信或银行卡已经扣款，但订单页面没有立即出现，可能是支付回调延迟。WildAI 的帮助文档建议等待，并在一段时间后重新查看订单，不要马上再次付款。

### 联系平台客服

如果超过平台说明的处理时间仍未开通，准备好以下信息：

- WildAI 订单编号
- 付款时间
- 支付截图
- ChatGPT 账户邮箱
- 当前 ChatGPT 计划页面截图
- 页面显示的错误信息

这些信息比一句“没开通”更容易让客服定位订单。

## 退款和取消需要提前确认

平台帮助中心说明，订阅已经完成履约、权益已经生效后，因选错套餐、误操作购买或购买后不想使用，原则上不支持退款。订单仍在处理中、订阅未生效，或者多月套餐中有尚未生效的月份时，可以联系客服核实是否符合退款条件，但不能把退款理解为自动保证。

因此，购买前至少确认四件事：

- 账号邮箱是否正确。
- 选择的是 Plus、Pro 5x 还是 Pro 20x。
- 购买的是单月还是长期方案。
- 结算页金额和支付币种是否符合预期。

这几个步骤看起来普通，却是最容易导致后续争议的地方。
